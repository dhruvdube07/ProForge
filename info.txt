4. KEY BACKEND API ENDPOINTS
------------------------------------------------------------------------
* Authentication (/api/auth)
  - POST /signup         : Validates registry details, dispatches a 6-digit OTP via Zoho SMTP.
  - POST /verify-otp     : Verifies OTP, signs up Supabase user, registers active login signature.
  - POST /login          : Verifies credentials, generates JWT access token, audits signature.
  - POST /resend-otp     : Clears old OTP sessions, triggers new email dispatch.
  - PUT  /update-profile : Updates user metadata.
  - POST /send-test-email: Dispatches SMTP diagnostic testing email.
* Profile Management (/api/profiles)
  - GET  /               : Fetches all candidate profiles belonging to the user.
  - GET  /:id            : Fetches specific profile detail.
  - POST /               : Creates new profile. Serializes custom fields (like experience,
                           education, contact) into the JSONB 'values' column.
  - PUT  /:id            : Updates owned profile.
  - DELETE /:id          : Deletes owned profile.
  - GET  /public/:idOrSlug: Read-only guest public endpoint. Resolves by UUID or custom slug.
* AI Analysis (/api/analyze)
  - POST /               : Analyzes raw text bio and structures it into JSON profile parameters.
  - POST /refine         : AI refinement based on sliders (creativity, length) & company context.
  - POST /ats-score      : Scores profile matching vs job description, lists missing keywords.
  - POST /ats-rewrite    : Rewrites a resume bullet to match targeted JD context.
* PDF & AI Generation (/api/generate)
  - POST /resume         : Downloads rendered PDF resume.
  - POST /resume-preview : Previews rendered PDF resume in browser.
  - POST /cover-letter   : Downloads cover letter PDF.
  - POST /linkedin       : Generates custom professional LinkedIn About summaries.
  - POST /outreach       : Generates pitch packages (LinkedIn, cold email, cover letter).
  - POST /linkedin-post  : Generates milestone-driven social media posts.
* Email Scheduling & Campaigns (/api/mali)
  - GET  /schedules      : Retrieves user's pending, sent, and failed email schedules. Seeding
                           mock example schedules on first retrieval.
  - POST /schedules      : Adds a scheduled or immediate email dispatch to the queue.
  - PUT  /schedules/:id  : Edits details of a pending scheduled email.
  - DELETE /schedules/:id: Cancels and removes email from the queue.
  - POST /generate       : Groq AI email draft generator using candidate details and target context.
